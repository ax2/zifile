## 定位

ZiFile 是一款面向 Windows 10/11 的现代压缩与文件工具。它希望提供比传统压缩软件更清晰的交互、更严格的安全默认值，以及可审计的开源构建链。

产品名使用 **ZiFile**，仓库为 `ax2/zifile`，发行方为 **ZiCode / zicode.com**，计划使用 WinGet ID `ZiCode.ZiFile`。

## 首版用户任务

1. 拖入或选择压缩包，快速查看内容。
2. 解压全部或选中的文件，清楚处理重名和风险。
3. 选择文件和目录，使用合适的格式、压缩等级与加密配置创建压缩包。
4. 在后台查看任务进度，并随时取消长任务。

## 首版之外

- 不创建 RAR。
- 不实现完整资源管理器。
- 不加入账号、云同步、广告或默认遥测。
- 不发明新的压缩格式。
- 不复制或派生 `ouch`、7-Zip、PeaZip 等项目代码。

## 后续扩展

架构为校验和、重复文件分析、批量重命名和文件预览保留扩展点，但这些能力不能拖慢压缩工具的首版交付。
