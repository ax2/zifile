根目录 [`ROADMAP.md`](https://github.com/ax2/zifile/blob/main/ROADMAP.md) 是路线图的唯一权威来源。本页提供面向读者的摘要。

| 阶段 | 目标 | 关键交付 |
| --- | --- | --- |
| Stage 0 | 验证基础 | Rust workspace、Iced、CI、Starlight、ADR |
| Stage 1（进行中） | Alpha | 已打通 ZIP/7z/TAR 家族、安全解压、主要 UI、真实进度与取消；继续互操作测试 |
| Stage 2 | Beta | Shell、隔离 Worker、签名安装升级和系统级性能验证 |
| Stage 3 | RC | 辅助功能、中英文、WinGet、Store、供应链证明 |
| Stage 4 | 1.0 | API 冻结、文档完成、三渠道正式发布 |

每个阶段必须有独立工作日志，记录目标、发现、修改、验证、遗留问题和发布结果。
