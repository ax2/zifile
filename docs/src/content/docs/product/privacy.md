生效日期与最近更新日期：2026 年 8 月 25 日。

ZiFile 由 ZiCode 发布，是一款采用 MIT License 的开源 Windows 压缩工具。本说明适用于 ZiFile 桌面应用、命令行工具、隔离 Worker 和资源管理器扩展。

## 我们不收集的数据

ZiFile 不要求账号，不包含广告、分析 SDK、默认遥测、云同步或自动崩溃上传。应用本身不会把文件名、路径、文件内容、压缩包内容、密码或使用行为发送给 ZiCode 或第三方服务。

## 本机处理

用户主动选择或拖入的文件和压缩包只在设备上处理。输入文件、生成的压缩包和解压结果由用户选择并保留在本机文件系统中。ZiCode 不接收这些内容，也不为其设置远程保存期限。

ZIP 与 7z 密码只为当前操作临时传递和使用，不会写入设置、日志或命令行参数。命令行密码通过标准输入读取。操作结束后，应用不会有意保留密码；和所有桌面程序一样，进程运行期间数据可能短暂存在于内存中。

ZiFile 仅在设备上保存界面语言和主题等非敏感偏好。用户可以通过应用设置或 Windows 的应用重置/卸载功能清除这些设置。

## 网络与第三方

当前 MSIX 只声明桌面完全信任能力，没有声明 Internet 客户端能力；ZiFile 不提供应用内网络服务。通过 Microsoft Store、GitHub 或 WinGet 下载和更新应用时，相应平台可能按照其自己的隐私条款处理网络与账号数据，这不属于 ZiFile 应用内的数据收集。

ZiFile 不出售、出租或共享个人数据，因为应用不会为 ZiCode 收集这些数据。开源依赖及其许可证记录在项目仓库和发布材料中。

## 儿童、变更与联系

ZiFile 是通用文件工具，并非面向儿童设计，也不会有意收集儿童数据。

如果应用未来加入需要网络或数据收集的可选功能，本说明会在功能发布前更新，并明确说明用途、范围、保存期限和控制方式。更新日期会显示在页面顶部。

隐私问题或删除请求可以通过 [ZiFile GitHub Issues](https://github.com/ax2/zifile/issues) 联系 ZiCode。由于当前应用不把用户文件或个人数据上传给 ZiCode，通常没有由 ZiCode 持有并可代为删除的应用数据。
