## 目标

形成可上架的 Release Candidate：完善双语 UI、辅助功能候选、发布自动化、商店材料、可复现构建和公开预发布流程。

## 证据范围

本页只汇总仓库中已有的实现和验证证据。Narrator、Accessibility Insights、正式签名、WACK、Partner Center、WinGet 接受和 Store 认证仍是外部门禁，缺失项保持未完成。

## 已交付

- Dioxus/WebView2 可访问候选复用 Rust 核心、隔离 Worker、任务栏和设置，提供语义导航、归档表格、筛选分页、选择、校验、解压、创建、进度、取消、拖放和核心快捷键。
- 候选增加本地资源/CSP 约束、双语键盘回归、页面切换后的主区域焦点、动态选择语义、高对比度样式和双语 About/运行版本信息。
- 默认 Iced UI 与候选共享格式能力、目录视图、操作队列和 Worker 协议；默认 UI 继续保留，直到完整辅助功能门禁完成。
- Starlight 文档、Store 双语文案、截图清单校验、WACK readiness、SBOM、来源证明、校验和和 Tag Release workflow 已接入仓库。
- GitHub 已发布公开 Alpha prerelease `v0.1.0-alpha.1`，Release Notes 包含 SignPath Foundation 代码签名说明；文档部署 workflow 已通过。

## 验证

- CI `33184493503` 和文档部署 `33184493619` 成功；Release `33184684164` 成功完成 x64/ARM64 构建、SBOM 和预发布产物上传。
- 本地 Rust 全量测试、严格 Clippy、打包策略、MSIX x64 构建审计、基础归档冒烟和 Astro 构建均通过。
- 2026-08-29 基础 Windows 冒烟新增并通过 9 种格式的真实 CLI 往返：TAR+Zstandard、TAR+XZ、TAR+Bzip2、gzip、Zstandard、XZ、Bzip2、LZ4 和 Brotli；每种格式均完成创建、完整性校验、解压和内容断言。
- 2026-08-29 核心新增改名 TAR 组合探测回归：TAR+gzip、TAR+Zstandard、TAR+XZ 和 TAR+Bzip2 改为 `.bin` 后仍能识别并列出，探测输入和解码头均受有界限制。
- 2026-08-29 两套桌面 UI 统一使用双语 Worker 错误格式化，覆盖取消、密码、未知格式、目标冲突和安全限制，并保留路径及后端诊断细节。
- 2026-08-29 创建路径回归拒绝源目录内部的输出目标，并确认拒绝发生在创建父目录或临时文件之前，避免自包含归档和空目录副作用。
- 2026-08-29 解压目标回归覆盖“目标本身是已存在文件”：核心在创建目录前返回结构化目标冲突，并确认原文件内容保持不变。
- 2026-08-29 创建目标回归覆盖“输出文件已经存在”：所有临时文件提交路径返回结构化目标冲突，并确认原文件内容保持不变；解压条目的显式覆盖策略不受影响。
- 2026-08-29 展开比限制改用无溢出的精确算术，并以临界值回归确认 `1000:1` 不会因整数除法截断而错误放行。
- 2026-08-29 偏好设置保存改为 flush/sync 后的临时文件原子替换，Windows 使用 `MOVEFILE_WRITE_THROUGH`，两套桌面 UI 会报告保存失败；临时目录替换回归通过。
- 2026-08-29 单流格式列出阶段与声明式展开比限制统一；`0` 比率严格禁止解码输出，并由 gzip 回归覆盖此前隐式最小值行为。
- 2026-08-29 TAR 列出阶段在跳过压缩载荷前检查累计声明条目大小与展开比上限；TAR、TAR+gzip、TAR+Zstandard、TAR+XZ、TAR+LZMA 和 TAR+Bzip2 均有回归覆盖。
- 2026-08-29 两套桌面 UI 的打开、解压目录、添加来源和保存归档对话框移出 UI 事件线程，并加入活动对话框门禁，避免慢速目录冻结或重复打开原生窗口。
- 2026-08-29 默认 Iced 状态栏引入 `Informational`/`Error` 语义；成功、进度、排队、取消和来源选择使用普通样式，Worker 失败、创建预检失败、队列已满、偏好设置保存失败和内部队列错误使用 danger 主题，并由桌面回归测试覆盖。
- 2026-08-29 两套桌面 UI 共享归档空状态四态判断：Worker 打开中显示进行中提示，密码错误显示解锁表单，其他打开失败显示重试提示，无待处理归档显示空闲引导；双语回归测试覆盖四种状态，修复了加载阶段误报失败。
- 2026-08-29 Iced 搜索栏补齐与可访问候选一致的匹配数摘要；0 项结果不再显示虚构的“第 1/1 页”，页码位置使用占位符，双语格式由共享函数和单测覆盖。
- 2026-08-29 修复 Iced 在归档打开请求排队或队列已满时提前清空当前归档的竞态；只有任务真正启动时才切换视图，并由两项回归覆盖排队和拒绝路径。
- 2026-08-29 两套桌面创建表单统一单流格式行为：添加文件使用单文件选择器，添加文件夹在 UI 与防御性路径均拒绝，Dioxus 创建预检失败改用错误语义播报；源码契约回归覆盖该分叉点。
- 2026-08-29 创建格式切换提取为可单测状态转换：两套 UI 都会钳制格式级别、清理不适用密码，并通过双语状态区播报来源要求。
- 2026-08-29 Windows Unicode 条目冲突回归使用 `Ä.txt`/`ä.txt`，确认列表阶段拒绝会在文件系统落盘时冲突的大小写变体。
- 2026-08-29 两套桌面创建表单在保存对话框前拒绝符号链接、junction 和 reparse point 来源，并用双语提示引导用户选择原始文件或文件夹。
- 2026-08-29 本地 x64 `0.1.0.10` 成品重新构建并通过 MakeAppx；包含 64 个文件，桌面、CLI、Worker 和 Shell DLL 均为 `0x8664`，Shell 双 CLSID、文件关联、图标、背景菜单、路径去重、背景路径预算和审计哈希均通过。最新 MSIX SHA-256 为 `1E5ABC05B9E67252D3B2377F5F3BDBEAC310A3F072DD130EAFAE49E5D0524778`。包使用开发 Identity 且未签名，不构成可信安装证据。
- 2026-08-29 可访问候选真实前台解压取消冒烟通过：128 个 1 MiB 条目中途取消，观察到双语取消错误，已提交文件均为完整条目大小、无部分输出文件，Worker 回收为 0。
- 2026-08-29 可访问候选双语键盘完整工作流连续 3 次通过；每次均覆盖页面正反向导航、归档校验/Reload/搜索/选择/冲突策略/分页、创建页 7z 与压缩等级 `6→7→6`、密码清除及来源控件，固定测试密码未写入证据。
- 2026-08-29 发布工作流修复正式 Store 身份变量的作用域：稳定 tag 和显式云签名演练才会传递正式身份，未签名 prerelease 与手动 `none` 校验保留 `.Dev` 身份；PowerShell 发布契约测试已锁定该分支。
- 候选已有 UI Automation、双语键盘、十万条目浏览/筛选/取消和内存基线证据；这些结果不等同于 Narrator 或正式辅助技术认证。
