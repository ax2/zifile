---
title: ADR-0002：格式 Provider 边界
description: 用能力驱动接口隔离归档格式实现。
---

- 状态：接受
- 日期：2026-08-23

## 决定

每种归档格式通过统一 Provider 边界接入。Provider 必须显式报告浏览、解压、创建、测试、加密、分卷和创建输入形态能力。创建输入形态区分“文件与目录”和“单个文件”，RAR 报告 RAR 5 创建能力，CAB 则报告固定 MSZIP 创建能力且不支持加密。

## 结果

- UI 不直接依赖具体压缩 crate。
- CLI 和桌面使用一致的能力与错误模型。
- 两套桌面 UI 可以在打开目标对话框或启动 Worker 前阻止无效创建来源。
- 可替换有安全或维护问题的后端。
- RAR 等具有独立兼容性或许可证问题的格式，以及 CAB 的有限固定布局写入器，都可以隔离评审。
- 基准、互操作和模糊测试能够按 Provider 独立运行。
